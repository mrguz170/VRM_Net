# Capa de Datos - Módulo Prospectos

## ?? OBJETIVO: Demostrar Cómo Conectarse a la Base de Datos

Este módulo es un **ejemplo simplificado** para entender el patrón de acceso a datos.

---

## ?? Conceptos Clave

### 1. **DatabaseHelper** (Infraestructura Compartida)
```csharp
// ? Registrado en Program.cs del Host
builder.Services.AddScoped<DatabaseHelper>(provider =>
{
    var configuration = provider.GetRequiredService<IConfiguration>();
    var connectionString = configuration.GetConnectionString("DefaultConnection");
    return new DatabaseHelper(connectionString);
});
```

**¿Qué hace?**
- Lee el connection string de `appsettings.json`
- Ejecuta stored procedures en MySQL
- Mapea resultados automáticamente a DTOs (snake_case ? PascalCase)

---

### 2. **DTOs** (Data Transfer Objects)
```csharp
public class ProspectoDto
{
    public int IdProspecto { get; set; }        // BD: id_prospecto
    public string RazonSocial { get; set; }     // BD: razon_social
    public string RFC { get; set; }              // BD: rfc
}
```

**¿Para qué sirven?**
- Representan la estructura de datos de la BD
- Mapeo automático de columnas de BD a propiedades C#

---

### 3. **Repositorios** (Acceso a Datos)
```csharp
public class ProspectoRepository : IProspectoRepository
{
    private readonly DatabaseHelper _dbHelper;
    
    public ProspectoRepository(DatabaseHelper dbHelper)
    {
        _dbHelper = dbHelper;  // ? Inyectado automáticamente
    }
    
    public async Task<List<ProspectoDto>> GetAllAsync()
    {
        return await Task.Run(() => 
            _dbHelper.ExecuteStoredProcedure<ProspectoDto>("sp_Prospectos_GetAll"));
    }
}
```

**Flujo de ejecución:**
1. Constructor recibe `DatabaseHelper` (DI)
2. Método llama a `_dbHelper.ExecuteStoredProcedure<T>()`
3. DatabaseHelper ejecuta el SP en MySQL
4. Convierte resultados a `List<ProspectoDto>`

## ?? 3 Métodos de Ejemplo

### 1. **GetAllAsync()** - Retorna lista
```csharp
// Sin parámetros, retorna todos los registros
var prospectos = await _repository.GetAllAsync();
```

### 2. **GetByIdAsync()** - Retorna un objeto
```csharp
// Con parámetro, retorna un registro
var prospecto = await _repository.GetByIdAsync(1);
```

### 3. **CreateAsync()** - Retorna ID generado
```csharp
// Inserta y retorna el ID
var dto = new CreateProspectoDto { RazonSocial = "Empresa", ... };
int id = await _repository.CreateAsync(dto);
```

## ? Ventajas de este Patrón

1. **DatabaseHelper centralizado** - Toda la lógica de conexión en un solo lugar
2. **Mapeo automático** - No código manual de conversión
3. **Tipo seguro** - DTOs con IntelliSense
4. **Testeable** - Interfaces permiten crear mocks
5. **Reutilizable** - Mismo patrón en todos los módulos
